Ultimate Manga Scraper: Madara Enhancements

Overview

The Ultimate Manga Scraper: Madara Enhancements plugin is designed to enhance the functionality of the Ultimate Web Novel & Manga Scraper by adding extra support for the Madara theme. This plugin ensures compatibility and provides additional features for a better manga scraping experience.

Installation

  1. Ensure that the following dependencies are installed and active on your WordPress site:
    • Madara Theme: A popular theme for manga websites. Download Madara Theme
    • Madara Core Plugin: Provides core functionality for the Madara theme. Should be included with the Theme if i recall.
    • Ultimate Web Novel & Manga Scraper Plugin: Scrapes manga and web novel data. Download Ultimate Web Novel & Manga Scraper Plugin
  2. Upload the plugin files to the /wp-content/plugins/ directory, or install the plugin through the WordPress plugins screen directly.
  3. Activate the plugin through the 'Plugins' screen in WordPress.

Admin Menu

After activation, the plugin adds a new menu item to the WordPress admin panel called "Madara Enhancements". You can find it in the main menu, and it provides access to the plugin's admin page.

Admin Page

The admin page provides several functionalities for managing manga scraping:

  • Set Manga Fetch URL: Allows you to specify the URL from which manga data will be fetched. This URL should point to the Madara theme's AJAX handler.
  • Search Manga: Provides a search form where you can search for manga using various search types including New, Latest, Trending, Most Viewed, Rating, A-Z, and Relevance.
  • Enable Auto Load More: Allows you to enable or disable automatic loading of more manga when scrolling to the bottom of the page.
  • View and Add Manga: Displays a list of manga and provides an option to add selected manga to your site.

Set Manga Fetch URL

You can set the URL from which manga data will be fetched. This URL should point to the Madara theme's AJAX handler. To set the URL:

  1. Navigate to Madara Enhancements in the admin menu.
  2. In the Set Manga Fetch URL section, enter the URL in the provided field.
  3. Click the Save URL button to save the URL.

Search Manga

You can search for manga using the provided search form. The search form allows you to specify a search query and select a search type. The available search types are:

  • New
  • Latest
  • Trending
  • Most Viewed
  • Rating
  • A-Z
  • Relevance

To search for manga:

  1. Navigate to Madara Enhancements in the admin menu.
  2. In the Search Manga section, enter your search query and select a search type.
  3. Click the Search button to perform the search.

Enable Auto Load More

You can enable or disable automatic loading of more manga when scrolling to the bottom of the page. To enable auto load more:

  1. Navigate to Madara Enhancements in the admin menu.
  2. In the Enable Auto Load More section, check the Enable Auto Load More checkbox.

View and Add Manga

The admin page displays a list of manga based on your search criteria. You can view the details of each manga and add selected manga to your site. To view and add manga:

  1. Navigate to Madara Enhancements in the admin menu.
  2. In the manga list, review the manga details including title, cover image, description, genres, status, last updated date, and latest chapter.
  3. To add a manga to your site, click the Add Manga button next to the desired manga.
